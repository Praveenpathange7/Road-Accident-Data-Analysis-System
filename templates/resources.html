Source quality rule

Keep the original publisher, publication date, reporting period, geography, and definition with every imported dataset. This website bundles State/UT accident totals for 2015–2024 and killed/injured detail for 2017–2023. Casualty details for 2015–2016 and 2024, plus population-normalized rates, are not currently bundled. State boundaries and report revisions differ across this decade; read the source notes before comparing trends.
